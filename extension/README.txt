正格点黑 16 全局字体扩展
========================

安装（Chrome 与 Edge 相同）：
1. 打开 chrome://extensions （Edge 打开 edge://extensions）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹（extension）
4. 固定扩展图标（可选）：点扩展图标 -> 图钉

使用：
- 默认开启：所有网页正文强制使用「正格点黑 16」
- 图标字体自动保留（Material Icons、Font Awesome、iconfont 等），避免乱码方块
- emoji 由系统字体自动回退，不受影响
- 点扩展图标可随时开关、恢复网页原始字体
- 修改后刷新页面完全生效

使用前请先安装系统字体：
- 推荐：在 fonts 目录任选一个 TTF，右键「为所有用户安装」
- 或运行「正格点黑」点「应用切换」
- 未安装时网页会回退到无衬线字体

浏览器建议：
- 网页默认字号请调大（如 18–24），16px 设计在默认字号下细节偏紧
- Chrome 可正常使用切换器写入的字体偏好
- Edge 已知问题：字体设置有时无法保存，并可能被覆盖为 Noto Sans SC
  若 Edge 无效，请用本扩展强制页面字体，或改用 Chrome

说明：
- 页面自身 CSS 优先级低于本扩展（!important），所以几乎所有网页都会变化
- 某些重度动态页面（如在线文档）滚动频繁，如感觉卡顿可关掉图标保留开关或整体关闭
